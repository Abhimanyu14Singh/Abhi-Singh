Known differences and assumptions

  • Example 3 seismic: -0.08 % is the gravity constant (386.09 vs 386.4 in/s2), identical to ETABS's own offset.
  • Example 3 wind: the UBC97 exposure / tributary convention behind the published forces is not documented and was not reproduced by any convention tried (level, integrated or mid-strip Ce; leeward at h or at z); SkyFrame's code-literal convention lands 2-4 % low. Treat the wind rows as a convention gap, not a solver result.
  • Example 6: the CSI comparison is between DIFFERENT mass models (story-lumped horizontal vs joint-lumped H+V); the +0.02 to +0.09 % gap of both ETABS and SkyFrame's ETABS-style model is that modelling difference, not solver error -- SkyFrame's reference-style model matches Bathe & Wilson to the printed digits.
  • Example 7: the section properties CSI used are unpublished; with AISC values SkyFrame (like an independent numpy frame) lands ~0.05 % from the reference -- an input gap, not a solver gap.
  • Example 15: ETABS's one/two-panel wall meshes under-predict the SAP2000 refined values by up to 21.6 % (1-story 120 in wall); CSI does not hold coarse meshes to the limits. SkyFrame is run with a refined mesh, so it is compared with the refined reference.
  • Example 15d/15f: the reference element formulation is not stated; the C-wall values are reproduced only by membrane walls and the E-wall values only by full shells. With the other formulation SkyFrame differs by: X-displacement, 6-story load X: shell: 0.7127 (-20.2 %); Z-rotation, 6-story load X: shell: 0.014078 (-26.3 %); Y-displacement, 6-story load Y: shell: 1.1835 (-0.4 %) | X-displacement, 6-story load X: membrane: 0.38284 (+4.7 %); Z-rotation, 6-story load X: membrane: 0.004279 (+9.7 %); Y-displacement, 6-story load Y: membrane: 0.75247 (+0.5 %).
  • Example 15b: re-entrant column/wall corners make the reference mesh-dependent; SkyFrame at the published SAP2000 mesh (20 in) matches it, finer meshes converge ~5-7 % softer (see the row notes).
  • P-Delta: SkyFrame (like ETABS) uses the chord ('string') geometric stiffness; on a 10-segment column it is 0.48 % below the exact beam-column -- the formulation, reproduced to 1e-6 by an independent numpy assembly (tests/verification).
  • Live-load reduction is off in every case; SkyFrame, like ETABS, never reduces live load in analysis output (reduced forces are separate tables).
  • EX02: partly blocked -- Table 2-2 (roof/2nd/1st RS displacements 2.139/1.716/0.955 in, C1 base moment 11,730 kip-in): needs the El Centro 1940 N-S 5 % spectrum ordinates, file ELCN-RS1 (ETABS install); not tabulated in the PDF.
  • EX05: partly blocked -- Table 5-1 axial forces (column C1 story 1: 279.47, brace D1: 194.51, brace D3: 120.53 kip, W&H): need the El Centro 1940 N-S spectrum ordinates (ELCN-RS1, ETABS install); the PDF also does not state the modal combination, the number of modes or which frame is reported.
  • EX07: partly blocked -- Table 7-3 RS (roof 5.4314 in, C1 axial 261.50 k, C1 moment 9916.11 kip-in, W&H CQC): needs the El Centro spectrum ordinates (ELCN-RS1).
  • EX07: partly blocked -- Table 7-4 TH maxima over 8 s (roof 5.48 in, base shear 284 k, C1 axial 258 k, moment 8740 kip-in, W&H): needs the ELCN-THU record (time step and format not in the PDF; TH damping not stated).
  • EX07: partly blocked -- Exact section A / I and E (published only in the SAP90 manual / Example 07.EDB): AISC values reproduce the frame to ~0.05 %.

Methodology

Each case module builds a SkyFrame model from the inputs printed in the CSI example (geometry, sections, materials, masses, loads); values read from figures or derived by hand are marked [derived], inputs that are not printed and had to be chosen are marked [assumed]. The real SkyFrame engine (OpenSees back end) runs every case; nothing is fitted to the answer.

Percent difference = 100 × (value / independent − 1). Where an example has several meshes only the finest must meet the limits (CSI). Periods, eigenvalues, mode shapes, story shears and displacements are rated as global quantities; member and station forces as internal forces. The ETABS column is CSI's own published result, shown for comparison; the rating is always against the independent reference.
